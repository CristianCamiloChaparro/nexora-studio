# NEXORA Studio

Editor audiovisual para Windows: video multipista, diseño de imagen, audio, color y 3D en un solo programa.

- **Sitio oficial:** https://cristiancamilochaparro.github.io/nexora-studio/
- **Usar en el navegador:** https://cristiancamilochaparro.github.io/nexora-studio/app/
- **Descargas:** [Releases](https://github.com/CristianCamiloChaparro/nexora-studio/releases)
- **Errores y soporte:** [Issues](https://github.com/CristianCamiloChaparro/nexora-studio/issues)

## Instalar

1. Descarga `NEXORA-Studio-Setup-0.1.0.exe` desde Releases.
2. Comprueba su SHA-256 en PowerShell:

```powershell
Get-FileHash .\NEXORA-Studio-Setup-0.1.0.exe -Algorithm SHA256
```

Debe ser `f6c74c983ab858a6c8420fdd04380df5abbead78698e24e8dd1308d8a8bdb61e`.

3. Ábrelo. El instalador aún no tiene firma digital, así que Windows mostrará un aviso: pulsa "Más información" y "Ejecutar de todas formas".

Este repositorio contiene las descargas y el sitio publicado.
